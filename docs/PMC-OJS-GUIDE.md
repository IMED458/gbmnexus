# GBMN → OJS → PubMed Central: სრული ინსტრუქცია

ეს დოკუმენტი აღწერს, როგორ მოამზადოთ სტატია ამ ხელსაწყოთი, როგორ ატვირთოთ OJS-ზე
და რა გზას გადის ჟურნალი PubMed Central-ში (PMC) და მის მეშვეობით PubMed-ში მოსახვედრად.

> **მთავარი:** PubMed-ში ჟურნალი პირდაპირ "განაცხადით" არ ხვდება. არა-MEDLINE ჟურნალისთვის
> გზა არის **PMC**: როცა PMC ჟურნალს მიიღებს და სტატიების სრულ ტექსტს (JATS XML) მიიღებს,
> ყოველი სტატიის ჩანაწერი PubMed-შიც ავტომატურად ჩნდება. ამიტომ ორი ცალკე განაცხადი
> არ გჭირდებათ: საკმარისია PMC.

---

## 1. სტატიის მომზადება ამ ხელსაწყოთი

1. **New article**: გაასუფთავებს წინა სტატიას (ჯერ შეგიძლიათ JSON-ად შეინახოთ).
2. **Import Word / PDF**: აირჩიეთ სტატიის `.docx`, ან ფაილი უბრალოდ ჩააგდეთ ფანჯარაში.
   - **Word (.docx) ყველაზე ზუსტია.** გადმოდის სათაური, ავტორები (აფილიაციის ნომრები, ORCID ბმულები,
     საკორესპონდენციო `*`), აფილიაციები, Received/Accepted/Published თარიღები, ტომი/ნომერი/პერიოდი,
     DOI, აბსტრაქტი (Background./Methods. ... სტრუქტურით), საკვანძო სიტყვები, სექციები
     ორიგინალი სათაურებით (მაგ. "Background"), ქვესათაურები, სურათები, ცხრილები
     (გაყოფილი ცხრილიც ერთდება), შენიშვნები ("Abbreviations", "Explanations") და ლიტერატურა.
   - **PDF**-იდან გადმოდის ტექსტი და მეტამონაცემები, ORCID-ების ჩათვლით. **სურათები არ გადმოდის**
     და ცხრილები შესამოწმებელია. თუ Word-ის ფაილი გაქვთ, გამოიყენეთ ის.
3. იმპორტის ფანჯარაში ნახავთ რა მოიძებნა და რა უნდა შეამოწმოთ. დააჭირეთ **Use this manuscript**.
4. შეავსეთ ის, რაც ფაილში არ არის:
   - ნაბიჯი 4: **Running title** (≤50 სიმბოლო) და **Specialty**.
   - ნაბიჯი 5: საკორესპონდენციო ავტორის **e-mail**.
   - ნაბიჯი 16: **First page / Last page** (ან E-location ID), **Publication date**, საჭიროებისას
     **PDF URL** (OJS-ზე PDF-ის ბმული, Google Scholar-ისთვის).
5. ჩამოტვირთეთ:
   - **PDF**: ბეჭდვის განლაგება (Print → Save as PDF).
   - **HTML**: ვებ-სტატია ORCID ლოგოებით, შინაარსით, მუქი რეჟიმით და Google Scholar-ის მეტა-თეგებით.
   - **JATS XML (.zip)**: PMC-სთვის. ფანჯარაში მიუთითეთ საბოლოო PDF, რომელიც ავტომატურად
     XML-ის სახელს დაერქმევა, და ნახეთ **Pre-flight check**: ✗ = PMC უარყოფს, ! = სასურველია.

### რა არის JATS პაკეტში

| ფაილი | დანიშნულება |
|---|---|
| `GBMN-2026-4-4-Author.xml` | NISO JATS 1.3, Journal Publishing DTD |
| `GBMN-2026-4-4-Author.pdf` | იგივე სახელი, რაც XML-ს აქვს (PMC ამას მოითხოვს) |
| `GBMN-...-fig1.png` … | თითო სურათი ცალკე ფაილად, `<graphic xlink:href>` ემთხვევა |
| `README.txt` | დეპოზიტის ინსტრუქცია |

XML-ში შედის: ISSN-ები, გამომცემელი, DOI და publisher-id, სტატიის ტიპი, ავტორები ORCID-ით და
`aff` ბმულებით, საკორესპონდენციო ავტორი, გამოქვეყნების და კოლექციის თარიღი, ტომი/ნომერი/გვერდები,
**history** (received/accepted), CC BY 4.0 ლიცენზია, `self-uri` PDF-ზე, **სტრუქტურირებული აბსტრაქტი**
(`<sec>` თითო ნაწილზე), საკვანძო სიტყვები, დაფინანსება, COI, **ტექსტში ციტატები დაკავშირებული
ლიტერატურასთან** (`<xref ref-type="bibr">`), ბმულები "Figure 1"/"Table 2"-ზე, ცხრილები
გაერთიანებული უჯრებით და ლიტერატურა (`mixed-citation`, ავტორის ორიგინალი ტექსტი, ამოცნობილი
ნაწილები მონიშნულია).

## 2. OJS-ზე ატვირთვა

OJS 3.3/3.4-ში JATS-ისთვის ოფიციალური ადგილი არ არის. რეკომენდებული სქემა:

1. **Submission → Production → Galleys → Add galley**:
   - Label **`PDF`** → ატვირთეთ `.pdf` (მთავარი ვერსია, ამას კითხულობს მკითხველი).
   - Label **`HTML`** → ატვირთეთ HTML ექსპორტი. სურათები შიგ არის ჩაშენებული, დამატებითი ფაილი არ სჭირდება.
   - Label **`JATS XML`** (სურვილისამებრ) → `.xml`. ეს ჩამოსატვირთი ფაილია და OJS მას გვერდად ვერ აჩვენებს,
     თუ არ დააყენებთ JATS Parser პლაგინს.
2. **Production → Production Ready files**: იქაც ატვირთეთ `.xml`. ამ ადგილას ეძებს მას PKP-ის
   **oaiJats** პლაგინი (Plugin Gallery-ში არის, OJS 3.4). ის JATS-ს OAI-PMH-ით გასცემს.
3. **Metadata**: ავტორები ORCID-ით, DOI, საკვანძო სიტყვები, აბსტრაქტი, ლიცენზია **CC BY 4.0**.
   ეს ველები უნდა ემთხვეოდეს XML-ს.
4. **DOI**: Crossref პლაგინით დაარეგისტრირეთ გამოქვეყნებისას. PMC DOI-ს ამოწმებს.
5. ჟურნალის საიტზე სავალდებულოა (PMC ამას ამოწმებს): სარედაქციო საბჭო აფილიაციებით,
   peer-review პოლიტიკა, ეთიკის/COI/კორექციის/retraction პოლიტიკა, ლიცენზია, საკონტაქტო მისამართი,
   ISSN-ები და ყოველი სტატიის ცალკე გვერდი.

> OJS-ის ჩაშენებული **PubMed XML Export** პლაგინი PMC-სთვის არ არის: ის PubMed-ის ციტატის ფორმატს ქმნის,
> რომელსაც მხოლოდ MEDLINE-ში ან PMC-ში მიღებული ჟურნალის data provider აგზავნის. PMC-სთვის გჭირდებათ
> სრული ტექსტის JATS. ამიტომ ხელსაწყო ცალკე აკეთებს JATS პაკეტს. "PubMed XML" ღილაკი იმ დღისთვისაა,
> როცა NLM ჟურნალს data provider-ის ანგარიშს მისცემს.

## 3. PMC-ზე განაცხადი: ეტაპები

ოფიციალური გვერდი: **pmc.ncbi.nlm.nih.gov → About → Add a Journal to PMC**. მოთხოვნები შეიძლება
შეიცვალოს, ამიტომ განაცხადამდე ოფიციალური გვერდი შეამოწმეთ.

1. **წინაპირობები** (განაცხადამდე):
   - ჟურნალს უნდა ჰქონდეს გამოქვეყნებული **მინიმუმ 25 peer-reviewed** კვლევითი სტატია ან მიმოხილვა
     (ზოგ ძველ წყაროში 40 წერია, მაგრამ მიმდინარე წყაროები 25-ს ასახელებენ).
   - შინაარსი ძირითადად ინგლისურ ენაზე.
   - ბიომედიცინის ან სიცოცხლის მეცნიერებების სფერო.
   - ISSN, DOI-ები, ღია ლიცენზია და საჯარო პოლიტიკები ვებგვერდზე.
2. **განაცხადი**: ონლაინ ფორმა. ივსება ჟურნალის, გამომცემლის და პოლიტიკების მონაცემებით.
3. **Screening**: NLM ამოწმებს სისრულეს და მოთხოვნებს. თუ უარი მიიღეთ, ხელახლა მხოლოდ
   **24 თვის შემდეგ** შეგიძლიათ. ამიტომ განაცხადამდე ყველაფერი მოაწესრიგეთ.
4. **Scientific quality review**: მეცნიერული და სარედაქციო ხარისხი, პოლიტიკები, ენის ხარისხი, პრეზენტაცია.
5. **Technical evaluation**: მოგთხოვენ **~25 სანიმუშო სტატიას** JATS XML-ად, PDF-ით და სურათებით,
   ჟურნალის ყველა ტიპის სტატიიდან. აქ გამოიყენეთ ამ ხელსაწყოს JATS პაკეტები.
   შეცდომების გამოსწორების **3 რაუნდია**. ამის შემდეგ შეიძლება უარი მიიღოთ.
6. **Pre-production → Live**: ხელშეკრულება, FTP ანგარიში, შემდეგ ყოველი ახალი სტატიის დეპოზიტი.
   PubMed-ის ჩანაწერები ჩნდება ავტომატურად.

### ტექნიკურ შეფასებამდე თვითშემოწმება

- [ ] თითო სტატიისთვის JATS პაკეტის **Pre-flight check**-ში ✗ არ არის.
- [ ] XML გაატარეთ **PMC Style Checker**-ში და **nXML / XML validator**-ში (PMC-ის საიტზე, ორივე უფასოა).
      თუ შეცდომაა, მითითებული ელემენტი გამოასწორეთ ხელსაწყოში და პაკეტი თავიდან ჩამოტვირთეთ.
- [ ] სურათების ხარისხი: PMC-ს სჭირდება მაღალი გარჩევადობა (ფოტო ≥300 dpi, ხაზოვანი გრაფიკა ≥600–1200 dpi).
      თუ Word-ში დაბალი ხარისხის სურათია, პაკეტში PNG ჩაანაცვლეთ ორიგინალით (TIFF), იგივე სახელით,
      და XML-ში `xlink:href`-ის გაფართოება შეცვალეთ.
- [ ] XML-ის და PDF-ის სახელი ერთნაირია, PDF და HTML/XML შინაარსი ერთმანეთს ემთხვევა.
- [ ] ყველა ავტორს აქვს ORCID, საკორესპონდენციო ავტორს e-mail.
- [ ] ლიტერატურაში DOI-ები სადაც არსებობს.
- [ ] `nlm-ta`: როცა NLM ჟურნალს ოფიციალურ შემოკლებას მიანიჭებს, ჩაწერეთ `src/part10.html`-ში
      (`JOURNAL.nlmta`) და გადააწყვეთ `./build.sh`-ით. მანამდე XML `iso-abbrev`-ს გზავნის.

## 4. ხშირი კითხვები

**PDF და HTML ავტვირთო თუ JATS XML?** OJS-ზე სამივე, როგორც ზემოთ წერია. PMC-ში მიდის
**JATS XML + PDF + სურათები** (პაკეტი). PMC HTML-ს არ იღებს.

**JATS XML OJS-ის რომელ ველში?** Galley "JATS XML" (ჩამოსატვირთად) და Production Ready files
(oaiJats პლაგინისთვის). საჭირო არ არის ის ვებგვერდად ჩანდეს.

**PubMed XML ღილაკი რისთვისაა?** PubMed-ის ციტატის ფორმატია. ის მხოლოდ MEDLINE-ის ან უკვე მიღებული
data provider-ის ანგარიშით იგზავნება. PMC-ის გზაზე არ გჭირდებათ.
